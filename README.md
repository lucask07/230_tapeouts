# FPGA to Tiny Tapeout

Student instructions for adapting a Verilog FPGA project to Tiny Tapeout, verifying its behavior, generating GDSII, and preparing a submission.

The first Markdown edition of the course instructions is available. The guides have been clarified and checked against official documentation; a worked example and complete build validation remain in progress.

- [Start the student guide](docs/index.md)
- [Prepare a Tiny Tapeout project](docs/tiny-tapeout.md)
- [Run LibreLane locally](docs/librelane.md)

- [Project plan and reference review](docs/project-plan.md)
- [Project authoring skill](SKILL.md)
- [Original references](starting_references/)

All projects use SKY130. Students complete the GitHub Actions workflow and a required local LibreLane lab in a preinstalled Ubuntu VirtualBox environment. Tile allocation and clock frequency depend on the project. The current endpoint is a submission-ready design; fabrication arrangements remain undecided.
